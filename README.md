# Python Contact Book

A command-line Contact Book application built in Python to efficiently store, search, update, and manage contacts.

## Features
- Add new contacts with phone numbers and details
- Search existing contacts quickly
- Update and delete contact records
- Clean, menu-driven CLI interface

## How to Run
1. Clone the repository:
   git clone https://github.com/mutahirnadeem126-gif/python-contact-book.git
2. Run the Python script:
   python contact_book.py
